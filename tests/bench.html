VOIDBORNE benchmark

Runs the debug build (dist/voidborne.debug.html, made by npm run build:debug) once per quality preset: the same scripted 8-shot camera path through the home system, the same seed, the preset's own render scale (no dynamic resolution). It records frame time, main-thread CPU (total and per system), GPU time per frame and per render pass when the browser offers EXT_disjoint_timer_query_webgl2, draw calls and render scale — overall, per shot and per second. Frame times come from the browser's frame callbacks, so with vsync on they cannot go below your display's refresh interval — for uncapped numbers run npm run bench, which starts Chrome without the frame-rate limit. Keep this tab in front while it runs. Meant for real devices: numbers from software rendering mean nothing.
